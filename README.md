# 待办进展（WorkLog）

macOS 本地离线工作台，把「每日计划」和「工作进展跟踪」放在同一个应用里。数据仅保存在本机，不联网、无账号、无遥测。

- 仓库：<https://github.com/sujiangtao-sun/worklog-macos>
- 安装包与操作视频：见 [Releases · v1.1.4](https://github.com/sujiangtao-sun/worklog-macos/releases/tag/v1.1.4)
- 原生 SwiftUI，单个 `.app`
- 系统 SQLite3 存储，零第三方依赖
- 富文本与图片存本地 RTFD 附件，自动日备份
- 深色/浅色模式、VoiceOver 标签

## 功能

### 日历待办

- 年 → 月 → 日三层浏览：点击左上角年月返回 12 个月总览，选择月份后点击日期查看当天事项
- 日历面板可一键隐藏/显示；隐藏后待办列表占满窗口，选择会被记住
- 每日事项逐条录入、独立成卡，不在一个大文本框里塞多条内容
- 每条事项记录：多行内容、计划完成时间、实际完成时间、难点、结果反馈
- 事项内容、难点、结果反馈均为多行编辑器，支持回车换行
- 计划完成时间可通过日历选择日期，并通过小时/分钟列表选择时间；修改日期后事项会移到新日期列表
- 状态圆点：
  - 绿色：已完成
  - 蓝色：今天待完成
  - 红色：过去日期未完成
  - 灰色：未来事项未开始
- 日历日期格显示事项数量和当日状态点
- 点击圆圈标记完成/撤销，实际完成时间自动写入当前时间；也可在编辑面板手动调整
- 长内容自动换行；支持点击日期查看历史记录

### 工作跟踪

- 工作项：标题、富文本工作内容（支持内嵌图片）、计划完成时间、实际完成时间
- “编辑内容/编辑工作项”弹框支持最大化/还原；最大化后富文本编辑区同步扩展
- 状态严格对应：`已完成` / `未完成` / 逾期时显示 `逾期 N 天` 或 `今日已超时`
- 已完成但晚于计划时显示 `逾期 N 天完成` / `超时完成`
- 每条进展都是独立富文本记录，支持多张内嵌图片；可逐条编辑，编辑后显示「已编辑」
- 进展按时间倒序展示；每条进展记录原始创建时间
- 工作列表筛选：全部 / 未完成 / 逾期 / 已完成
- 删除有二次确认；删除工作项会级联删除进展和图片附件，并在下次启动清理孤儿附件

### 富文本

- 工具栏：粗体、斜体、下划线、删除线、字号调整、左/中/右对齐、插入图片
- 图片支持文件选择、剪贴板粘贴、拖拽；插入前按最长边约 1600px 降采样
- 内嵌图片按内容区等比缩略；点击图片打开预览窗口，可切换“适应窗口/原始大小”
- 富文本以 RTFD 包保存，图片随 RTFD 一起落到本地附件目录
- 只读展示自动测量高度；读档失败时降级显示数据库中的纯文本，并提示附件缺失

## 状态与时间规则

| 场景 | 展示 |
|---|---|
| 每日事项 `actual_at` 非空 | 绿色「已完成」 |
| 每日事项未完成、日期早于今天 | 红色「未完成」 |
| 每日事项未完成、日期是今天 | 蓝色「待完成」 |
| 每日事项未完成、日期晚于今天 | 灰色「未开始」 |
| 工作项未完成且未到计划时间 | 蓝色「未完成」 |
| 工作项未完成且已过计划时间 | 红色「逾期 N 天」/「今日已超时」 |
| 工作项已完成且未晚于计划 | 绿色「已完成」 |
| 工作项已完成且晚于计划 | 绿色「逾期 N 天完成」/「超时完成」 |

设计取舍：

- **完成状态只有 `actual_at` 一个事实源**，不额外存布尔值，避免状态分叉；取消完成即清空实际时间。
- 每日事项的计划时间日期部分锁定在该事项所在日，只调整时分；每日「未完成变红」按自然日切换，与计划时刻无关。
- 工作项逾期天数按自然日差计算（计划日开始到参照日开始）；同日但超过计划时刻显示「今日已超时」，跨日显示「逾期 N 天」；逾期完成后按实际完成日计算逾期天数。
- 状态色点始终配文字/无障碍标签，不只靠颜色。

## 技术架构

```
Sources/
├─ WorkLogCore               # 无 UI 依赖的核心层
│  ├─ Models / CalendarSupport / StatusCalculator
│  ├─ Database + Migrations  # 系统 SQLite3 封装、事务、user_version 迁移
│  ├─ WorkLogStore           # actor，串行化所有数据库访问
│  ├─ RichTextStore          # RTFD 原子读写、纯文本镜像、孤儿清理
│  ├─ BackupService          # 一致性数据库快照 + 附件拷贝 + 轮转 + 导出
│  └─ DataPaths              # 本地数据/附件/备份路径
└─ WorkLogApp                # SwiftUI + AppKit 富文本组件
   ├─ AppModel               # @MainActor @Observable 全局状态
   ├─ 日历 / 每日待办 / 工作跟踪
   ├─ RichTextEditor         # NSTextView 富文本编辑器 + 工具栏
   ├─ RichTextDisplay        # 只读自适应高度展示
   └─ 设置与备份
Tests/WorkLogCoreTests       # Swift Testing
```

- **并发**：数据库读写收敛在 `actor WorkLogStore`；UI 状态在 `@MainActor`；跨线程只传 Sendable 值模型。
- **SQLite**：WAL、外键、busy timeout、显式事务；按 `user_version` 迁移；日常操作全部参数绑定。
- **数据模型**：
  - `daily_items`：日期、排序、多行内容、计划/实际时间、难点、反馈
  - `work_tasks`：标题、富文本路径、纯文本镜像、计划/实际时间
  - `work_progress`：所属工作项、富文本路径、纯文本镜像、创建/更新时间
  - 外键级联删除进展；附件删除在数据库提交后执行，失败由启动时孤儿扫描兜底。
- **附件**：`attachments/<uuid>.rtfd`，只存相对路径；路径解析阻止目录穿越。
- **备份**：SQLite backup API 生成一致性数据库快照，再复制附件；临时目录写入完成后原子改名；自动备份每天最多一次，保留 7 份。
- **无网络代码**：应用代码不发起网络请求，不加载远程 URL；图片仅来自本地文件或剪贴板；无账号、无遥测。

## 构建、测试与安装

环境要求：macOS 15+、Swift 6（本机已验证 macOS 27 / Swift 6.4）。**无需完整 Xcode 即可构建**。

### 直接安装（Apple Silicon）

1. 从 [Releases](https://github.com/sujiangtao-sun/worklog-macos/releases/tag/v1.1.4) 下载 `WorkLog-1.1.4-macOS.zip`。
2. 解压后把 `WorkLog.app` 拖入「应用程序」。
3. 应用为 ad-hoc 签名、未公证，首次启动可能需要在「系统设置 → 隐私与安全性」中允许；详见压缩包内 `INSTALL.txt`。

### 从源码构建

```bash
git clone https://github.com/sujiangtao-sun/worklog-macos.git
cd worklog-macos

# 运行核心单元测试（Swift Testing）
./scripts/test.sh

# 构建并 ad-hoc 签名 .app → dist/WorkLog.app
./scripts/build_app.sh

# 安装到 ~/Applications
./scripts/install.sh
open ~/Applications/WorkLog.app
```

说明：

- 本机只安装了 Command Line Tools。当前工具链的默认 SwiftPM `swiftbuild` 引擎在此环境下会报 plist 解析错误，因此脚本显式使用 `--build-system native`。
- CLT 未附带 XCTest，测试使用 Swift Testing；`scripts/test.sh` 会自动把 `Testing.framework` 加入编译参数。
- 本地构建只做 ad-hoc 签名，没有公证；这是个人本机使用的预期行为。
- 如果后续安装完整 Xcode，可以直接用 Xcode 打开 `Package.swift` 开发，宏与预览能力会更完整。

## 数据目录、备份与恢复

| 内容 | 路径 |
|---|---|
| 数据库 | `~/Library/Application Support/WorkLog/worklog.sqlite` |
| 富文本附件 | `~/Library/Application Support/WorkLog/attachments/` |
| 自动备份 | `~/Library/Application Support/WorkLogBackups/` |

- 每天首次启动或应用重新激活时自动备份一次；备份包含数据库与附件；保留最近 7 份。
- 设置页提供：立即备份、显示数据/备份目录、导出数据（包含 `worklog.sqlite`、`attachments/` 与恢复说明）。
- 恢复步骤：
  1. 退出应用；
  2. 备份或移走现有数据目录；
  3. 把备份/导出中的 `worklog.sqlite` 与 `attachments/` 复制回数据目录；
  4. 重新打开应用。
- v1 不提供应用内一键恢复，避免误覆盖。

## 隐私说明

- 仓库不包含数据库、备份、账号、邮箱或本机数据。
- 应用代码不发起网络请求，不包含第三方依赖或遥测；富文本图片来自本地文件或剪贴板。
- 数据保存在本机 `~/Library/Application Support/WorkLog/`；数据库未额外加密，依赖 macOS 账户权限，敏感数据建议开启 FileVault。

## 快捷键

- `⌘N`：日历页聚焦快速添加；工作页打开新建工作项
- `⌘T`：回到今天
- `⌘S`：表单内保存
- `Esc`：取消表单
- `⌘,`：设置

## v1 范围
